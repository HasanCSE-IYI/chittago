# 🚀 GitHub Actions CI/CD Build Guide

এই প্রজেক্টটিতে সরাসরি **GitHub Actions**-এর মাধ্যমে ক্লাউডে স্বয়ংক্রিয়ভাবে Android APK বিল্ড করার সম্পূর্ণ ব্যবস্থা প্রস্তুত করা আছে।

---

### ১. GitHub-এ ওয়ার্কফ্লো যুক্ত করার সহজ পদ্ধতি (১ মিনিট):

যেহেতু আপনার গিটহাব ওঅথ (OAuth) টোকেনে ডিফল্টভাবে `workflow` পারমিশনটি সুরক্ষিত থাকে, তাই সরাসরি ব্রাউজার থেকে এটি ১ ক্লিকে যুক্ত করা যায়:

1. আপনার ব্রাউজারে এই সরাসরি লিংকটি ওপেন করুন:
   👉 **[Add Workflow on GitHub](https://github.com/HasanCSE-IYI/chittago/new/main?filename=.github/workflows/build-apk.yml)**
2. নিচের কোডটুকু কপি করে বক্সে পেস্ট করুন:

```yaml
name: Build Android APK

on:
  push:
    branches: [ main ]
    tags:
      - 'v*'
  pull_request:
    branches: [ main ]
  workflow_dispatch:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build:
    name: Build Debug APK
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'

      - name: Setup Gradle
        uses: gradle/actions/setup-gradle@v4

      - name: Grant Execute Permission to Gradlew
        run: chmod +x gradlew

      - name: Build Android Debug APK
        run: ./gradlew assembleDebug --stacktrace

      - name: Upload APK Artifact
        uses: actions/upload-artifact@v4
        with:
          name: Chittago-Debug-APK
          path: app/build/outputs/apk/debug/app-debug.apk
          retention-days: 14

      - name: Create GitHub Release (On Version Tag)
        if: startsWith(github.ref, 'refs/tags/v')
        uses: softprops/action-gh-release@v2
        with:
          files: app/build/outputs/apk/debug/app-debug.apk
          name: Release ${{ github.ref_name }}
          body: |
            ### Chittago (চিটাগো) - Chattogram Division Map & Navigation
            Automated release build generated by GitHub Actions.
            - **Target Division:** Chattogram (11 Districts)
            - **Engine:** OpenStreetMap + Leaflet + OSRM + Komoot Photon
            - **Download:** Download `app-debug.apk` below and install on your Android device.
          draft: false
          prerelease: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. নিচে স্ক্রল করে **"Commit changes..."** বাটনে ক্লিক করুন।

---

### ২. APK ডাউনলোড করার নিয়ম:
* ফাইলটি কমিট হওয়ামাত্র GitHub Actions স্বয়ংক্রিয়ভাবে ক্লাউডে বিল্ড শুরু করবে।
* বিল্ড শেষ হলে GitHub রিপোজিটরির **[Actions](https://github.com/HasanCSE-IYI/chittago/actions)** ট্যাবে যান।
* লেটেস্ট বিল্ডে ক্লিক করলেই নিচে **Artifacts** সেকশনে `Chittago-Debug-APK` নামে জিপ ফাইল ডাউনলোড করতে পারবেন, যার ভেতর সরাসরি অ্যান্ড্রয়েড ফোনে ইনস্টলযোগ্য `app-debug.apk` থাকবে।
